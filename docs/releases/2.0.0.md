PdfThumbnails draws first-page thumbnails for PDF files in Windows File Explorer, on the desktop
and in File Open dialogs, alongside [PdfCraft](https://github.com/storytold/pdfcraft) or any other
PDF app. 2.0.0 is its first public release.

## Download

**`PdfThumbnails-2.0.0-setup.exe`** (under Assets): one setup for x64 and ARM64 PCs. It installs
for all users of the PC, asks for administrator rights once, and adds PdfThumbnails to Installed
apps and the Start menu. Made for Windows 11; Windows 10 (version 1809 or later) is allowed by the
setup but not tested. For a silent install: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`.

## Not code-signed yet

This release is **unsigned**. That means:

- **SmartScreen warns** when the setup starts ("Windows protected your PC"). Choose **More info**,
  then **Run anyway**.
- **Smart App Control blocks it.** On a PC where Smart App Control is on, Windows blocks the
  downloaded setup and offers no way to allow it. There, [build from
  source](https://github.com/Avivash-Git/PdfThumbnails/blob/main/docs/BUILDING.md), or wait for a
  signed release.
- **Signing is planned** through [SignPath Foundation](https://signpath.org)'s free code signing
  for open-source projects, which accepts only projects that are already released. Signed files
  will name SignPath Foundation as their publisher. See the [code signing
  policy](https://github.com/Avivash-Git/PdfThumbnails/blob/main/docs/CODE_SIGNING.md).

## Coming from 1.x

Run the setup; there is no need to uninstall 1.x first. It replaces a 1.x install (its build
folders, its scheduled task, its sign-in clean-up and the files it copied into
`%LOCALAPPDATA%\Programs\PdfThumbnails`) and keeps your zoom. The PowerShell manager
(`PdfThumbnails.cmd`) is gone: use the **PdfThumbnails** settings window from the Start menu, or
`PdfThumbnailsCli.exe` ([how the 1.x commands
map](https://github.com/Avivash-Git/PdfThumbnails/blob/main/docs/CLI.md#coming-from-1x)). Every
change from 1.1 is in the
[changelog](https://github.com/Avivash-Git/PdfThumbnails/blob/main/CHANGELOG.md).

## Uninstalling

From **Settings > Apps > Installed apps** (PdfThumbnails, **Uninstall**), or with **Uninstall** in
the settings window. Either removes PdfThumbnails for all users of the PC. Thumbnails File
Explorer already made stay until it makes them again, unless you use the window's Uninstall with
**Also clear the thumbnail cache** (or `PdfThumbnailsCli.exe --uninstall --rebuild-thumbnails`),
which rebuilds the cache and restarts File Explorer.

## What's new in 2.0

- A settings window: zoom with a live preview, the scheduled checks, a status with a Fix link,
  Check now, Rebuild thumbnails, Copy diagnostics and Uninstall.
- A new zoom reaches the thumbnails File Explorer already made, without restarting it.
- An installer with an entry in Installed apps; every user of the PC is set up at their next
  sign-in.
- An ARM64 build.
- A command line, `PdfThumbnailsCli.exe`, that does everything the window does.
